# Euchre Trainer

A beginner-friendly euchre training app for learning suits, trump, bowers, scoring, and guided practice hands.

## Run Locally

```bash
node server.js
```

Then open `http://127.0.0.1:3000/`.

## Deploy

This app is static and can be hosted with GitHub Pages from the repository root. The public app uses:

- `index.html`
- `styles.css`
- `app.js`

`server.js` is only for local testing.
